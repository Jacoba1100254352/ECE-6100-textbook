Readable-book revision

Objective
Revise the complete course companion into clear, connected prose with relevant
lecture anecdotes and explanatory graphics. Preserve technical depth, examples,
and the separate chapter answer sheet. Attribute lecture material to evidence.

Completed in the first editorial pass
- Narrative openings connect the ten chapters through waiting, overlap, data
  movement, and communication.
- Source-supported slide examples restore the jet-simulation, Cray-vector,
  independent-addition, rate-averaging, and register-renaming context.
- Five recording-based examples have note/recording/time references, including
  construction scheduling, the power-wall design question, aircraft throughput,
  supercomputer pricing, and a full cache set versus a full cache.
- New diagrams and timing views explain dependencies, Amdahl's limit, cache lookup,
  pipeline overlap, translation/lookup overlap, false sharing, release/acquire,
  network bisection, register versions, result-bus contention, and loop draining.
- NUMA locality and dirty shared ownership now have separate diagrams, so
  shared addressing is not confused with equal distance and an S holder is not
  assumed to prove that backing memory is current in a protocol with O.
- A folded-ring placement diagram replaces an incorrect geometric claim, and
  a one-qubit phase/interference diagram supplies a concrete quantum example.
- Typography, running heads, front matter, contents depth, chapter openings,
  captions, and PDF metadata have been revised.
- Corrections distinguish buffering from speculation, equal-work from equal-time
  rate averaging, atomicity from ordering, reservation failure from interference,
  dynamic from guided scheduling, and unitary gates from measurement/reset.
- Bisection definitions and affected answers now include all equal partitions.
- The FICO practice trace now states timing assumptions and has a matching key.

Detailed reading and audit pass
- Chapters 1-10 and Appendices A-F have had a section-level
  reading pass; lecture supplementation and final whole-book QA remain open.
- Cache corrections distinguish TLB misses, page faults, and storage I/O;
  write-through propagation, coherence, and persistence; physical address width
  and installed RAM size; and full-block traffic versus early-use latency.
- Tiling handles partial edge tiles and states footprint/alignment assumptions.
- The pipeline guide now separates multi-cycle occupancy from issue width and
  avoids inferring a blocking cache from a stalled core alone.
- Predictor descriptions state the local-history variant, update context,
  training threshold, and BTB/RAS policies used by the examples and exercises.
- Independent calculations reproduced the GSelect and local-history tables and
  the integrated ten-iteration trace (23 misses, 19 writebacks).
- Dynamic-ILP corrections separate result eligibility from broadcast, speculative
  and committed maps from copied register values, and scheduler-ready checks
  from full-width operand reads. A single CDB no longer publishes two results
  in one cycle, and the faulting instruction is included in precise recovery.
- Static-ILP examples state memory-alias, resource, latency, register-lifetime,
  branch-control, and exit assumptions. The finite loop drains its last load
  before issuing the final store, including the one-iteration early-exit case.
- Independent schedules reproduce the seven-instruction FICO trace, four-op
  CDB trace, VLIW block heights and packing, and modulo kernels for 1-8 trips.
- Coherence examples now state the traffic policy, distinguish a per-block
  directory order from a cross-address memory model, and separate dirty-owner
  responsibility from readable shared copies. Inclusion tracks presence, not
  necessarily identical current bytes in all levels.
- Synchronization code uses atomic polling and acquire/release operations.
  The reusable barrier includes an ordered arrival chain and phase publication;
  transactional lock elision subscribes to its fallback lock and bounds retries.
- The prose distinguishes C/C++ data-race undefined behavior from logical races
  using relaxed atomics, and strict real-time order from deterministic scheduling.
- Independent checks reproduced the MSI trace, false-sharing transfer counts,
  directory sizes, and every SC interleaving in the two worked examples.
  A C++ rendition of the barrier passed 20,000 reusable phases each with 1, 2,
  4, and 8 threads. Stress results supplement, not replace, the ordering argument.
- Network explanations separate physical transfers, flits, header latency, and
  whole-packet latency; define the direction used for cut bandwidth; and avoid
  treating virtual channels as automatic deadlock or fairness guarantees.
- All 6,435 distinct balanced partitions confirm the 4x4 mesh/torus cut counts.
  Per-link schedules reproduce packet-latency formulas; channel-dependency
  checks distinguish XY routing on the mesh from torus wraparound cycles.
- Advanced topics now distinguish unitary gates from measurement/reset, correct
  SYNDRA's name using a public primary source, label illustrative models as such,
  and state a Carnot cooling bound rather than a universal refrigeration ratio.
- The formula reference now includes assumptions, variable meanings, equal-work
  versus equal-time averaging, and conditional miss-ratio conventions.
- All 123 chapter questions and the 10 advanced true/false prompts have matching
  answers, for 133 total pairs. The current book and
  answer sheet build without warnings; revised figures and source pages have
  been rendered and inspected. Whole-book visual QA is still outstanding.

Remaining before the complete revision can be declared finished
- Review the available lecture recordings, using automatic transcripts as drafts
  rather than as authority for exact quotations, names, numbers, or anecdotes.
- Integrate additional useful lecture stories with source/time references.
- Check continuity across the complete book and remove unhelpful duplication
  from front matter or reference prose while preserving useful study aids.
- Reconcile each changed exercise or convention with the answer sheet.
- Inspect the final rendered book across every chapter, appendix, and new figure.
- Commit and push completed work; tag and publish the finished distribution.

Local source handling
Lecture audio, draft transcripts, recognition logs, and their local source
inventory belong under ignored no-include/lecture-transcripts, not in GitHub.
The public source appendix identifies the handouts and anecdotes actually used.

Build
Run make all to build the textbook and answer sheet with latexmk/pdfLaTeX.
The design uses lmodern, microtype, fancyhdr, titlesec, caption, booktabs,
enumitem, and TikZ in addition to the original LaTeX packages.
Run make clean to remove intermediate build files while keeping the PDFs.
